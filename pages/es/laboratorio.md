El laboratorio es el banco de trabajo: aquí se **monta**, se **rompe** y se **investiga**. Cada entrada es un paso reproducible, documentado y versionado — nada de capturas sueltas sin contexto.

Esta primera serie es la vía **manual**: levantar un laboratorio de Active Directory a mano, de bare metal a GOAD, con dos años de ruido histórico y su pipeline de imagen forense. La base sobre la que, más adelante, cada caso se recorre en tres actos: <span style="color:var(--red)">el crimen</span>, <span style="color:var(--green)">la defensa</span> y <span style="color:var(--blue)">la investigación</span>.
